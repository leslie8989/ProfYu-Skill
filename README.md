## 关于这个 Skill

你好，欢迎体验「蒸馏我的导师于文轩」。

本工具由厦门大学公共事务学院于文轩教授的学生们研发，借助 AI 系统梳理并凝练于老师日常指导论文写作的经验。从**开题构思、结构梳理到文本精修**，愿这份工具为你的论文写作带来切实的启发与帮助。

它可用于学术写作构思、起草、润色、总结和审校，也可辅助公共管理研究中的选题讨论、理论对话与研究设计。它不会替代研究者对文献、数据、伦理和最终稿件的核验。

<sub>内容由学生整理，仅供学习参考，不代表于文轩老师本人意见；Skill 的指导意见亦仅供参考。</sub>
