## 关于这个 Skill

你好，欢迎体验「蒸馏我的导师于文轩」。

本工具由厦门大学公共事务学院于文轩教授的学生们研发，借助 AI 系统梳理并凝练于老师日常指导论文写作的经验。从开题构思、结构梳理到文本精修，愿「于老师」为你的论文写作带来切实的启发与帮助。

它可用于学术写作构思、起草、润色、总结和审校。它不会替代研究者对文献、数据、伦理和最终稿件的核验，也不应被用于伪造数据、编造文献或冒充研究结果。

内容由学生整理，仅供学习参考，不代表于文轩老师本人意见；本Skill 的指导意见亦仅供参考，不为指导意见负任何责任。

本工具在开源项目「女娲Skill」（NuwaSkill）基础上蒸馏、二次开发而成，特此鸣谢。

## 常见问题

### 介绍网页和安装包有什么区别？

介绍网页用于了解项目和查看使用向导；ZIP 安装包用于安装 Skill。仅打开介绍网页不会完成安装。

### 为什么只发链接后，Codex 没有直接安装？

单独的网址不一定能明确表达安装意图。回复“请安装这个 Skill”即可继续；是否能完成安装还取决于当前环境的网络和文件访问权限。

### 安装后找不到 Skill 怎么办？

请让 Codex 检查安装目录和 `SKILL.md` 是否完整，并确认配套资源一同安装。根据提示重新加载会话或重启客户端。

### AI 的建议可以直接用于论文吗？

请自行核实文献、数据、事实与方法适用性。AI 建议仅供研究与写作参考，不能替代导师指导、学术判断或研究伦理审查。
